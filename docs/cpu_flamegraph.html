Vector CPU Execution Flamegraph & Bottleneck Analysis

Hardware Profile: AMD Zen 3 / Intel x86-64 • AVX2, FMA3 • Clang/GCC/MSVC

● Naive std::vector Bottleneck

83.5% Time in Malloc

Naive temporary buffers create heap allocations on every stage. Page faults and free-list mutex locks dominate execution latency.

● vec_math Zero-Allocation

64.55x Speedup

Expression templates fuse vector arithmetic into a single register pass with 0 B heap allocations and zero redundant loads.

● Memory Bandwidth Ceiling

32 - 35 GB/s DDR4

When vector size exceeds L3 cache (16 MB), execution hits physical memory bus saturation. SIMD streaming stores bypass cache lines to preserve bandwidth.

● Contractions & Matvec

Unit-Stride SIMD

Loop-interchanged tensor contractions and row-span dot products eliminate register spills and maintain full AVX2 FMA throughput.

Key Profiling Findings & Vec_Math Optimization Targets

Subsystem / Kernel Identified CPU Bottleneck Observed Flamegraph Impact Applied Optimization Strategy
Fused Expressions (out <<= ...) Memory bandwidth saturation at >1M elements. DRAM bus contention at 5M elements; cache misses on 40MB working sets. Single-pass register evaluation with zero temporary allocations; non-temporal stores for out-of-cache buffers.
Reductions (sum, dot) Accumulator dependency serialization. Latency stalls when folding vector accumulators sequentially. Dual YMM vector accumulators breaking dependency chains (2 cycles per 8 elements); 512-element deterministic blocking.
Tensor Contractions (contract_axis) Strided non-unit memory access on Axis 1 (Y) and Axis 2 (Z). Cache line waste and TLB stalls from strided loads in inner loops. Loop interchange turning strided inner loads into contiguous, streaming unit-stride FMAs.
Matrix-Vector (matvec, matvec_fixed) Compiler over-unrolling and register spilling for matrix sizes > 20. Codegen cliffs between -O2 and -O3. Vectorized row-span dot products using AVX2 FMA with zero register spills across all optimization levels.
Batched Solver (solve_4x4_batched) Branching in partial pivoting and reciprocal calculations. Branch mispredictions and conditional pivot checks. Branchless SIMD blend and vectorized reciprocal multiplication with strict singularity diagnostics.
Parallel Scaling (dot_par, sum_par) Scalar loop evaluation inside OpenMP parallel sections. Loss of hardware SIMD acceleration across multi-threaded chunks. Vectorized chunk delegation to hardware SIMD `dot()`/`sum()`, eliminating scalar bottlenecks across all cores.
