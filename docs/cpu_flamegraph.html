CPU Performance & Profiling Report

Vector CPU Execution Flamegraph & Bottleneck Analysis

Target System: AMD Ryzen 5 5500 (6 Cores / 12 Threads, AVX2, FMA3) • Workload: benchmark.exe and bench_ofast.exe.

● Naive std::vector Bottleneck

83.5% Time in Malloc

In run_size_benchmark, naive std::vector creates 5 heap allocations per call (t1, t2, t3, t4, out). Malloc, free, and page-fault locks account for 83.5% of total naive latency.

● vec_math Zero-Allocation

64.55x Speedup

Expression templates fuse arithmetic into a single register pass with 0 B heap allocations. Throughput reaches 43.10 GFLOPS at 1K elements and 20.24 GFLOPS at 10K elements.

● Memory Bandwidth Ceiling

32 - 35 GB/s DDR4

At 1M and 5M elements (8 MB to 40 MB), working set exceeds L3 cache (16 MB). Execution becomes DRAM bound. Streaming stores (_mm256_stream_pd) bypass cache to preserve bandwidth.

● FP Divider Bottleneck

14 Cycle Latency

In bench_ofast fused expression, vector division b / c (_mm256_div_pd) takes 60.7% of compute cycles due to the non-pipelined hardware FPU divider.

Key Profiling Findings & Vec_Math Optimization Targets

Subsystem / Kernel Identified CPU Bottleneck Observed Flamegraph Impact Target Optimization Strategy
Fused Expressions (out <<= ...) Division latency (_mm256_div_pd 14 cycles) and memory bandwidth at >1M elements. 60.7% of compute time in bench_ofast; L3 cache eviction at 5M elements. Apply reciprocal approximation (_mm256_rcp_ps + Newton-Raphson) where applicable; non-temporal stores for N > 1M.
Reductions (sum, dot) Accumulator dependency chain serialization when folding SIMD registers. 28.9% of reduction time spent in horizontal fold instructions. 4-way ILP unrolled accumulators before tree reduction; preserve 512-element deterministic blocking for reproducibility.
Tensor Contractions (contract_axis) Strided non-unit memory access on Axis 1 (Y) and Axis 2 (Z). 75.9% of contraction time spent on strided accesses due to cache line waste. Loop blocking / tiling (e.g., 32×32 blocks) to maintain temporal cache locality for strided pencils.
Matrix-Vector (matvec) Inner product reduction loop register spilling for matrix sizes > 36. 64.7% compute time in column loop. Register-blocked 4×4 micro-kernel with broadcast loads; zero stack buffer overhead.
Batched Solver (solve_4x4_batched) Branching in partial pivoting and reciprocal calculations in back-substitution. 53.8% of solver time in row swaps and conditional pivot checks. Branchless SIMD blend (_mm256_blendv_pd) for row swaps; vectorized reciprocal multiplication.
Parallel Scaling (assign_par) OpenMP fork/join barrier latency on small vectors (<100K) and false sharing. 41.9% of multi-core benchmark in vcomp140.dll barrier synchronization. Schedule dynamic chunks with minimum chunk size ≥ 4096 elements; cacheline padding (64 bytes).
